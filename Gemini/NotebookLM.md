# Document summarization
```
Create a comprehensive document covering the core topics of the provided text.
Retain all key data points, facts, and main arguments.
Remove all conversational filler, redundancies, and tangential details.
Use language that is accessible, simple, and direct.
```

# Mind mapping
```
Create a hierarchical mind map from the provided text.
Extract all core topics, key data points, and relationships.
Exclude all filler, redundancies, and tangential details.
```
